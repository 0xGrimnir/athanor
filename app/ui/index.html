    How each number is validated

    Every tier is checked two ways. Correctness: Athanor must reproduce the underlying engine's own reference results. Accuracy: each tier's errors against experimental data must be consistent with the method's published error statistics. These are the error bars shown next to results.

    Sample

    Ancient reads are simulated from a real mitochondrial genome with gargammel, so the true sequence is known and every reconstructed base can be scored.

    References to map against
    Simulation

    Iterative mapping (Briggs et al. 2009) replaces confident consensus bases into the reference and re-maps, reducing reference bias against a relative's genome.

    Runs in the Linux engines pack: gargammel → AdapterRemoval → BWA aln (ancient-DNA settings) → mapDamage2 → damage-aware consensus → scoring against the truth. Takes a few minutes.

    Reads

    FASTQ (paired-end or single-end, may be gzipped) or BAM, such as the files deposited with a publication. Files are read where they are, on this computer; nothing is uploaded.

    Method and sources
    Aligned reads

    An ancient genome as a BAM aligned to the human reference GRCh37 (hs37d5, hg19 or 1000 Genomes naming), such as the file deposited with a publication. It is read on this computer and never uploaded. A whole-genome BAM can be hundreds of gigabytes; only the positions needed are read from it.

    Genotypes

    Deamination turns C into T near a molecule's 5′ end and G into A near its 3′ end. Trimming the ends or keeping only transversions removes those errors at the cost of sites.

    Deamination

    With the reference genome the reads were mapped to, every aligned base is compared with it, as mapDamage2 does, and cytosines followed by guanine are counted separately: methylated CpG deaminates several times faster. Without it the rate can only be measured at the reference panel's own positions, which are few and CpG-rich, so it runs higher than a genome-wide figure.

    None: deamination will be measured at the panel's positions.

    Heterozygosity (high coverage)

    Heterozygous sites per callable base in one region, counted from the reads without a reference sequence. Published values use callers built for ancient DNA and each study's own filters, so compare like with like.

    No mask: every position with enough depth counts.
