About this data

Mitochondrial genomes are complete GenBank sequences (via GetOrganelleDB), annotated here by homology alignment. Nuclear karyotypes use NCBI cytogenetic bands and Ensembl 110 gene coordinates. Everything is public reference data — composite, anonymized, no individual's DNA.

DNA Report Explorer

Load a Promethease report (or any CSV/JSON of genotypes) and this charts every variant by magnitude and rarity, so the findings that matter rise to the top-left. Your file is read locally and never leaves this device — this page contains no genetic data until you load some.

Sample uses well-known public variants with illustrative genotypes — not a real person. Magnitude is SNPedia's interest score, not medical advice.
