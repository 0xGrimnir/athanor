Athanor pre-release. Phase 1: molecule workbench with MMFF94, GFN2-xTB and DFT (Psi4), validated against published data.

**First launch** unpacks the science engines (about a minute). Windows SmartScreen may warn about an unknown publisher because the app is not code-signed yet: choose **More info → Run anyway**.

See the in-app **Validation** tab for how each tier is checked and its measured error statistics.
